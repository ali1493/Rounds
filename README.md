# Rounds

A volunteer driver's companion app for Meals on Wheels delivery operations.

**Track:** Food Security Delivery Operations
**Event:** BuildersVault Social Services Hackathon, Victoria BC, April 2026

## What this is

Rounds gives volunteer drivers real agency over their shifts while the system
enforces the safety rules — severe allergies, wheelchair accessibility,
closure/deceased status — that today live only in the head of whichever
long-time volunteer happens to be on shift.

Designed for a first-shift volunteer who has no tribal knowledge, using a
mobile-web interface that makes safety-critical information legible at the
point of care.

## Validation

Constraint enforcement is validated against the full 3,453-stop synthetic dataset
generated by the BuildersVault Track 2 kit. Every stop runs through three
constraint checks before it could be shown to a driver.

### Numbers

| Constraint | Stops affected | Routes affected |
|---|---|---|
| Severe allergen warnings (driver attention) | 1,320 | 182 |
| Post-closure delivery attempts (blocked) | 144 | 17 |
| Wheelchair-vehicle mismatches (blocked) | 105 | 40 |

**Routes with at least one blocked stop: 53 of 300 (18%).**

The system would prevent 249 violations from reaching the depot, including
144 attempts to knock on a closed or deceased client's door.

### How to reproduce

```bash
python -m scripts.validate_ground_truth
```

### Tests

11 unit tests cover the three constraint checks. Run:

```bash
pytest tests/ -v
```
